Кубики Ефрона Чотири дивні кубики, ви обираєте першим. Це перевага?Ні: ви виграєте лише 1 кидок з 3.

На столі чотири кубики з незвичними числами на гранях. Суперник чемно пропонує: «Обирайте першим, а я візьму один з тих, що лишаться». Кожен кидає свій кубик, виграє більше число. Яким буде ваш шанс, якщо суперник обирає з розумом? Зафіксуйте відповідь, а потім перевірте: зіграйте проти комп'ютера, порахуйте всі пари й прочитайте пояснення.

На столі чотири кубики з незвичними числами на гранях. Здається, що, обираючи першим, ви візьмете найкращий і виграватимете щонайменше половину кидків. Але найкращого кубика тут немає: A б'є B, B б'є C, C б'є D, а D б'є A, щоразу з шансом 2/3. Хоч що ви візьмете, суперник знайде кубик, який виграє 2 кидки з 3.

Умова задачі

Чотири кубики й чемний суперник

Кубики звичайні, шестигранні й чесні: кожна грань випадає з шансом 1/6. Незвичні лише числа на гранях. Подивіться на них уважно, перш ніж обирати.

  1. 1

    Чотири кубики

    На гранях кубика A чотири четвірки й два нулі. На B шість трійок. На C дві шістки й чотири двійки. На D три п'ятірки й три одиниці.

  2. 2

    Ви обираєте першим

    Ви берете будь-який кубик. Суперник бачить ваш вибір і бере один з трьох, що лишилися.

  3. 3

    Кидаєте разом

    Кожен кидає свій кубик, і виграє той, у кого випало більше число. Нічиїх із цими кубиками не буває: у різних кубиків немає однакових чисел.

  4. 4

    Питання

    Суперник знає ці кубики так само добре, як ви, і обирає з розумом. Який ваш шанс виграти кидок?

Інтуїція каже

«Обираю першим, тож візьму найкращий кубик і виграватиму щонайменше половину кидків»

Насправді найкращого кубика немає. Кожен програє якомусь іншому з шансом 2/3, і суперник завжди бере саме його. Ваш шанс 1/3, хоч що ви оберете.

Кубики на столі

  • Кожна грань випадає з шансом 1/6, кидки незалежні.
  • Один кидок кожного, більше число виграє.
  • Суперник обирає після вас, бачачи ваш кубик.

Турнір «кожен з кожним»

Нехай кубики зіграють між собою, як команди в лізі: перемога в парі, якщо кубик виграє більше половини кидків, 3 очки за перемогу, 1 за нічию (В–Н–П: перемоги, нічиї, поразки). Таблиця точна, з тих самих дробів.

Чемпіон ліги C має найбільше перемог і найбільше середнє число на гранях, проте програє B, на якому завжди лише трійка. Таблиця ліги впорядковує кубики, але кожен з них хтось б'є.

Після вашої відповіді тут з'явиться код симуляції, який можна запустити в себе.

Перевірте самі в коді

Та сама симуляція коротко і без бібліотек. JavaScript запускається в консолі браузера (F12) або в Node, Python потребує лише стандартної бібліотеки.

JavaScript
// Чотири кості Ефрона. Ви обираєте кість першим, суперник бере одну з решти, і виграє більше число. Який ваш шанс, якщо суперник обирає найкращу відповідь?
const DICE = { A: [4, 4, 4, 4, 0, 0], B: [3, 3, 3, 3, 3, 3], C: [6, 6, 2, 2, 2, 2], D: [5, 5, 5, 1, 1, 1] };
const N = 100000;                                          // кидків на кожну пару
const roll = d => d[Math.floor(Math.random() * 6)];
const names = Object.keys(DICE), win = {};
for (const x of names) for (const y of names) if (x !== y) {
  let w = 0;
  for (let i = 0; i < N; i++) if (roll(DICE[x]) > roll(DICE[y])) w++;   // нічиїх у цих костях не буває
  win[x + y] = w / N;                                      // частка кидків, де x більше за y
}
for (const me of names) {
  // суперник бере ту кість, яка найчастіше б'є вашу
  const reply = names.filter(y => y !== me).reduce((a, b) => win[b + me] > win[a + me] ? b : a);
  console.log('Ви', me, '· суперник', reply, '· ваш шанс', (1 - win[reply + me]).toFixed(3), 'точно 1/3 = 0.333');
}
Python
# Чотири кості Ефрона. Ви обираєте кість першим, суперник бере одну з решти, і виграє більше число. Який ваш шанс, якщо суперник обирає найкращу відповідь?
import random

DICE = {"A": [4, 4, 4, 4, 0, 0], "B": [3, 3, 3, 3, 3, 3], "C": [6, 6, 2, 2, 2, 2], "D": [5, 5, 5, 1, 1, 1]}
N = 100_000                                                # кидків на кожну пару

win = {}
for x in DICE:
    for y in DICE:
        if x != y:
            # нічиїх у цих костях не буває
            w = sum(random.choice(DICE[x]) > random.choice(DICE[y]) for _ in range(N))
            win[x + y] = w / N                             # частка кидків, де x більше за y

for me in DICE:
    # суперник бере ту кість, яка найчастіше б'є вашу
    reply = max((y for y in DICE if y != me), key=lambda y: win[y + me])
    print("Ви", me, "· суперник", reply, "· ваш шанс", f"{1 - win[reply + me]:.3f}", "точно 1/3 = 0.333")
Раунд 4 · Пояснення

«Камінь, ножиці, папір» з чисел

Інтуїція думає, що кубики можна вишикувати від найкращого до найгіршого, і перший просто бере верхній. Але «виграє частіше» — це не число, яке можна приписати кожному кубику, а стосунок між двома кубиками. І такий стосунок може замкнутися в коло.

На пальцяхкартинки, аналогії, маленькі числа

Шар «На пальцях» приховано на всіх задачах.

Головне за хвилину

Кожен кубик когось б'є і комусь програє

Стрілка веде від переможця до переможеного. A б'є B, B б'є C, C б'є D, а D б'є A, щоразу 2 кидки з 3. Як у «камінь, ножиці, папір»: немає найкращого жесту, є лише відповідь на жест суперника. Тому хто обирає другим, завжди бере кубик, що стоїть у колі перед вашим.

Ця картка показує, що відбувається, але ще не чому таке можливо. Наступна картка рахує кожну стрілку на пальцях.

Чотири дуелі

Кожна стрілка складається з простих часток

A проти B · 2/3На B завжди 3. A виграє, коли випадає 4: це 4 грані з 6.
B проти C · 2/3Трійка програє лише шістці, а шісток на C дві з шести. Решту 4 з 6 разів випадає 2, і трійка виграє.
C проти D · 2/3Шістка на C (шанс 1/3) б'є все. Двійка (шанс 2/3) б'є лише одиницю на D, тобто половину разів: 2/3 · 1/2 = 1/3. Разом 1/3 + 1/3 = 2/3.
D проти A · 2/3П'ятірка на D (половина разів) б'є все на A. Одиниця (теж половина) б'є лише нуль, а нулів на A третина: 1/2 · 1/3 = 1/6. Разом 1/2 + 1/6 = 2/3.

Кожен кубик зроблений так, щоб бити сусіда, і платить за це слабкістю проти іншого сусіда. B тримає стабільну трійку: цього досить проти рідкісних шісток C, але замало проти частих четвірок A.

Середнє не вирішує

Найбільше середнє в C, а програє він B

Середнє число вимірює, скільки очок кубик набере за багато кидків. Але гра питає інше: чиє число більше в одному кидку. Велика шістка в C додає багато до середнього, проте виграє в дуелі так само, як виграла б четвірка: перемога є перемога, хоч на 1, хоч на 4. Тому середні можна вишикувати в ряд (C, потім B і D, потім A), а дуелі ні.

Усі 36 результатів

Таблиця 6 × 6 для кожної пари

Два кубики разом дають 6 · 6 = 36 рівноймовірних пар граней. Рядок — грань першого кубика, стовпець — другого, колір клітинки — хто виграв. У чотирьох стрілках кола переможець забирає 24 клітинки з 36, тобто 2/3. Через коло, у парах A–C і B–D, перевага менша або її немає зовсім: 20 з 36 і 18 з 36.

Найкраща відповідь

Чому саме 1/3, а не менше

Для кожного вашого кубика суперник порівнює три варіанти й бере той, що виграє найчастіше. Проти A найкращий D (2/3), бо C дає лише 5/9, а B 1/3. Проти B найкращий A (2/3). Проти C найкращий B (2/3). Проти D найкращий C (2/3).

Найкраща відповідь щоразу дає рівно 2/3, тож ваш вибір нічого не змінює: шанс 1/3 з будь-яким кубиком. Якби ви обирали навмання, а суперник теж навмання з решти, ви вигравали б рівно половину: кожна пара з'являлася б в обидва боки.

Для тих, хто любить формули

Шанс перемоги як сума за гранями

Перший кубик виграє, якщо випало x, а на другому менше за x.

P(X>Y)=∑xP(X=x)·P(Y<x)

Глибшеузагальнення, теорія, історія

Шар «Глибше» приховано на всіх задачах.

Транзитивність

Чому «кращий за» не мусить бути транзитивним

Відношення транзитивне, якщо з «A краще за B» і «B краще за C» випливає «A краще за C». Для чисел це завжди так: 5 > 3 і 3 > 2, отже 5 > 2. Інтуїція переносить це на кубики, ніби кожен кубик — одне число «сили». Але кубик — це шість чисел, а «частіше викидає більше» порівнює всі 36 пар граней. Таке порівняння не зводиться до одного числа, і транзитивності ніщо не гарантує.

Найкоротший приклад ховається в магічному квадраті 3 × 3. Візьміть його рядки {4, 9, 2}, {3, 5, 7} і {8, 1, 6} як грані трьох кубиків (кожне число двічі). Тоді {8, 1, 6} б'є {3, 5, 7}, {3, 5, 7} б'є {4, 9, 2}, а {4, 9, 2} б'є {8, 1, 6}, щоразу з шансом 5/9. Це те саме, що три виборці з парадоксу Кондорсе: кожна пара програє більшості, і переможця немає.

Теорія й історія

Турніри, вибори й гра Пенні

Коли про кожну пару відомо, хто сильніший, математики називають це турніром: граф, де між будь-якими двома вершинами одна стрілка. Турнір упорядковується в рейтинг, лише якщо в ньому немає циклів. Кубики Ефрона дають цикл з чотирьох, і жодне впорядкування не погодиться з усіма дуелями: хоч як поставити A, B, C, D у рядок, хоча б одна стрілка йтиме проти нього.

Маркіз де Кондорсе помітив такі цикли ще 1785 року у виборах, де кандидатів порівнюють попарно. Монетний варіант тієї ж ідеї — гра Пенні: на будь-яку трійку орлів і решок є трійка, що випадає раніше, і другий гравець знову має перевагу. А парадокс Паррондо показує інший бік тієї самої пастки: інтуїція про «гірше» і «краще» ламається, коли ігри поєднують.

Раунд 5 · Ускладнюємо

Два кубики, межа переваги й ящірки

Цикл може перевернутися, якщо кинути по два кубики. Перевага в циклі має стелю. А «камінь, ножиці, папір» грають і вибори, і бактерії, і ящірки.

Математика

Сума двох кидків грає за іншими правилами

Кинути два однакові кубики й скласти — означає грати новим «кубиком» на 36 граней. Його шанси залежать уже не лише від того, як часто кубик перемагає, а й від того, як розкидані його числа. Тому цикл може зламатися або навіть перевернутися.

Кубики Ефрона з двома кидками вже не утворюють кола: C частіше виграє, ніж програє, проти кожного з трьох. А п'ять кубиків Джеймса Ґрайма придумано так, що одне з двох їхніх кіл з двома кубиками перевертається повністю. Гравець, який обирає другим, ще й вирішує, грати одним кубиком чи двома, і знову виграє.

Наскільки сильною може бути кожна ланка циклу? Для трьох незалежних випадкових величин (кубики — окремий випадок) найменший шанс у колі не може перевищити (√5 − 1)/2 ≈ 0,618, обернене золоте число (Станіслав Трибула, 1961). Залман Усіскін 1964 року показав, як знайти цю стелю для будь-якої кількості: для чотирьох вона рівно 2/3, тож кубики Ефрона найкращі можливі, а з ростом кількості стеля наближається до 3/4.

Логіка

Порівняння парами не завжди дає рейтинг

Той самий магічний квадрат дає й вибори. Нехай його рядки 4 9 2, 3 5 7 і 8 1 6 — оцінки трьох кандидатів, а кожен стовпець — бюлетень одного виборця: вища оцінка означає вище місце. Перевірте самі: у кожній парі кандидатів двоє виборців з трьох за одного й лише один за другого.

Ірина (рядок 4 9 2) перемагає Олега (3 5 7) 2 : 1 (виборці 1 і 2), Олег перемагає Марка (8 1 6) 2 : 1 (виборці 2 і 3), а Марко перемагає Ірину 2 : 1 (виборці 1 і 3). Хоч кого оголосити переможцем, більшість воліла б іншого. Так само в спорті: команда, що виграла в лідера, може програти аутсайдеру, і таблиця з очками лише ховає цикл. А в A/B-тестах, де варіанти порівнюють попарно, «B кращий за A» і «C кращий за B» ще не означають, що C кращий за A: це треба перевіряти окремо. Більше про вибори — у парадоксі Кондорсе.

Практика

Де «камінь, ножиці, папір» грає природа

Цикл без найсильнішого не дає жодному гравцеві перемогти назавжди. Тому в природі такі цикли підтримують різноманіття: кожен вид чи стратегія тримається, бо має свою «жертву».

Що розповісти друзям

Грудень 1970

Колонка Мартіна Ґарднера

Широкий світ дізнався про ці кубики з колонки «Mathematical Games» у Scientific American за грудень 1970 року: «Парадокс нетранзитивних кубиків і невловимий принцип байдужості». Ґарднер описав там кубики стенфордського статистика Бредлі Ефрона.

Баффет і Ґейтс

«Обирайте першим»

Часто розповідають, що Воррен Баффет запропонував Біллу Ґейтсу зіграти такими кубиками й чемно дав йому обирати першим. Ґейтс роздивився кубики, щось запідозрив і наполіг, щоб першим обирав Баффет. Цю історію переказує, зокрема, Scientific American (2023).

2/3

Більше з чотирьох не вичавити

Залман Усіскін 1964 року довів, що в циклі з чотирьох незалежних випадкових величин найслабша ланка не може бути сильнішою за 2/3. Кубики Ефрона мають рівно 2/3 на кожній ланці, тож ніякі чотири кубики не зроблять пастку для першого гравця ще глибшою.

0,618

Золотий переріз у трьох кубиках

Для трьох кубиків стеля переваги — обернене золоте число (√5 − 1)/2. Станіслав Трибула довів це 1961 року. Кубики з цілими гранями можуть лише наближатися до цього ірраціонального числа: магічний квадрат дає 5/9 ≈ 0,556.

× 2

Кубики Ґрайма

Математик Джеймс Ґрайм придумав п'ять кубиків з двома різними колами перемог: одне йде за абеткою англійських назв кольорів, друге за довжиною цих назв. Якщо кожен кидає по два кубики, коло за довжиною перевертається, а за абеткою тримається, за одним винятком: стрілка між червоним і оливковим.

1975

Кубики Мівіна

Фізик Міхаель Вінкельман 1975 року зробив три кубики з гранями 1, 2, 5, 6, 7, 9; 1, 3, 4, 5, 8, 9 і 2, 3, 4, 6, 7, 8. У кожного однакова сума граней, 30, і середнє 5. Проте кожен б'є наступного в колі: 17 кидків з 36 проти 16, а решта 3 нічиї.
