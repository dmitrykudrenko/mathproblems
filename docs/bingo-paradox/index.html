The bingo paradox 500 cards in the hall, and someone shouts "Bingo!" Which line did they get?Usually a row: almost 2 to 1.

American bingo: a 5 × 5 card, the caller draws balls numbered 1 to 75 at random, and players mark their numbers. Whoever first completes a full row or a full column wins. There are 500 players in the hall. Is the first winning line more often horizontal, vertical, or equally often either? Lock in your answer, then check it: play in the hall, run thousands of games and read the explanation.

On one card a row and a column really are equally likely. But in a hall of 500 cards the first winning card has only a row in 63% of games, only a column in 35%, and both at once in 3%. A column needs five numbers of one letter, and every card waits for that together. A row needs one number of each letter, and which ones differs from card to card, so in a big hall somebody gets lucky sooner.

The puzzle

A hall, a caller and 500 cards

This is ordinary American 75-ball bingo. There are many cards in the hall, all different. The balls come out in random order, with no repeats.

  1. 1

    The card

    Five columns headed B I N G O. Column B has five different numbers from 1 to 15, I from 16 to 30, N from 31 to 45, G from 46 to 60, O from 61 to 75. The centre square is free: it is marked from the start.

  2. 2

    The caller

    The caller draws balls one at a time and announces each with its letter: "G 54!" Everyone who has that number marks it on their card.

  3. 3

    The win

    The first card with a whole row marked (a horizontal line) or a whole column (a vertical one) wins. Diagonals don't count in this hall. If several cards complete a line on the same ball, they all win.

  4. 4

    The question

    There are 500 players in the hall, each with one card. Somebody shouts "Bingo!" Is their line more often horizontal, more often vertical, or are both equally likely?

Intuition says

"A card has 5 rows and 5 columns of 5 squares. It's all symmetric, so equally"

For one card that is true. But the first winning card in the hall is not just any card; it is the luckiest one. And rows get lucky more often, because each card waits for its own numbers, while the columns of every card wait for the same thing: for the caller to call five numbers of one letter.

Check it yourself in code

The same simulation, short and with no libraries. Run the JavaScript in your browser console (F12) or in Node; the Python needs only the standard library.

JavaScript
// 75-ball bingo: 500 cards in the hall, the first full row or column wins. Which line does the first winning card have more often?
const CARDS = 500, GAMES = 20000;
// k different numbers out of n in a row starting at from, in random order
function pick(from, n, k) {
  const a = Array.from({ length: n }, (_, i) => from + i);
  for (let i = 0; i < k; i++) { const j = i + Math.floor(Math.random() * (n - i)); [a[i], a[j]] = [a[j], a[i]]; }
  return a.slice(0, k);
}
// a card: 5 columns B I N G O, each with 5 numbers from its own fifteen; the centre is free (0 = already marked)
const card = () => [0, 1, 2, 3, 4].map(c => { const col = pick(15 * c + 1, 15, 5); if (c === 2) col[2] = 0; return col; });
let onlyH = 0, onlyV = 0, both = 0;
for (let g = 0; g < GAMES; g++) {
  const when = [0];                                                    // which ball called each number
  pick(1, 75, 75).forEach((b, i) => { when[b] = i + 1; });
  let first = 99, h = false, v = false;
  for (let k = 0; k < CARDS; k++) {
    const t = card().map(col => col.map(x => when[x]));               // t[c][r]
    const col = Math.min(...t.map(c => Math.max(...c)));               // first full column
    const row = Math.min(...[0, 1, 2, 3, 4].map(r => Math.max(...t.map(c => c[r]))));  // first full row
    const m = Math.min(row, col);
    if (m < first) { first = m; h = row === m; v = col === m; }
    else if (m === first) { h = h || row === m; v = v || col === m; }  // several cards on the same ball
  }
  if (h && v) both++; else if (h) onlyH++; else onlyV++;
}
const p = x => (100 * x / GAMES).toFixed(1) + '%';
console.log('Only horizontal:', p(onlyH), '· only vertical:', p(onlyV), '· both on the same ball:', p(both));
console.log('For comparison, 200,000 games: 62.6% · 34.7% · 2.7%');

# 75-ball bingo: 500 cards in the hall, the first full row or column wins. Which line does the first winning card have more often?
import random

CARDS, GAMES = 500, 2000                                   # Python is slower, so fewer games: about 1 point of noise


def card():
    # 5 columns B I N G O, each with 5 numbers from its own fifteen; the centre is free (0 = already marked)
    cols = [random.sample(range(15 * c + 1, 15 * c + 16), 5) for c in range(5)]
    cols[2][2] = 0
    return cols


only_h = only_v = both = 0
for _ in range(GAMES):
    order = random.sample(range(1, 76), 75)
    when = {b: i + 1 for i, b in enumerate(order)}         # which ball called each number
    when[0] = 0
    first, h, v = 99, False, False
    for _ in range(CARDS):
        t = [[when[x] for x in col] for col in card()]     # t[c][r]
        col = min(max(c) for c in t)                       # first full column
        row = min(max(c[r] for c in t) for r in range(5))  # first full row
        m = min(row, col)
        if m < first:
            first, h, v = m, row == m, col == m
        elif m == first:                                   # several cards on the same ball
            h, v = h or row == m, v or col == m
    if h and v:
        both += 1
    elif h:
        only_h += 1
    else:
        only_v += 1

p = lambda x: f"{100 * x / GAMES:.1f}%"
print("Only horizontal:", p(only_h), "· only vertical:", p(only_v), "· both on the same ball:", p(both))
print("For comparison, 200,000 games: 62.6% · 34.7% · 2.7%")
Round 4 · Explanations

One train for all, a taxi for each

Intuition compares a row and a column on one card, and there they really are equal. But the question is about the first card in the hall, the luckiest of 500. And rows and columns get lucky in different ways.

In plain wordspictures, analogies, small numbers

The core in a minute

A column waits for the caller, a row waits for luck

Here are the first 10 balls of one game and the caller's board after them:

For anyone in the hall to have a full B column, the caller must call five B numbers (four for N: its centre is free). Here no letter has reached five, so nobody has a column: not one of the 500 players, not one of a million. Every column in the whole hall waits for the same thing: how the letters come out.

But a row is already possible: every letter has come out at least once. A player with, say, 7, 22, 40, 51 and 68 in one row needs nothing more. Any particular card is unlikely to hold that combination, but 500 cards carry 2,500 rows, and each is a lottery ticket of its own. It's like a station: columns leave on one train, and none of 500 passengers leaves before it does. Rows hail taxis, each their own, and out of 500 people someone gets a taxi very quickly.

This card shows why columns are held back, not by how much. The numbers come next, in the "Strict" layer.

One card

Why it really is equal on one card

Reflect the card in its diagonal: rows become columns and columns become rows. The free centre stays put. For one card it doesn't matter which fifteen a number belongs to: balls come out at random, so every order of its 24 numbers is equally likely. The reflected card plays exactly like the original, with rows and columns swapping roles.

So on one card "only a row" happens exactly as often as "only a column" (46% each), and in 7% more of the games the last ball completes a row and a column at once: it is the square they share.

The hall

The first in a crowd is the luckiest

When there are many cards, the winner is not an average card but the luckiest one. So the question "which line is more common?" turns into another one: "which line is easier to get lucky with for at least one of 500?"

For rows, 500 cards mean 2,500 different attempts. For columns they mean far less than it seems: every B column in the hall is made of the same 15 numbers and queues for the same balls. The bigger the hall, the more rows gain, and in a hall with every possible card the row comes first in 74% of games.

Rigoroustables, charts, formulas

A race of two counters

When a line becomes possible at all

Both curves are exact, counted from how many numbers of each letter are among the first balls. Pink: the caller has called at least one B, I, G and O number, so the middle row (with its free centre) can be complete on some card. Blue: some letter has come out five times (four for N), so a full column can exist somewhere. After 10 balls a row is possible in 66% of games, a column in only 20%.

For one card this means nothing yet: "possible somewhere" is not "on yours". But the more cards there are, the closer "possible" comes to "somebody already has it". In a hall with every possible card, the first "Bingo!" comes exactly when one of the curves fires, and the pink one is first in 73.73% of games.

Shared numbers

Columns of different cards look alike, rows don't

5/3 ≈ 1.7numbers shared by the B columns of two random cards, on average
1/3 ≈ 0.3numbers shared by a row of one card and a row of another

Each of the five numbers of the second B column is in the first with chance 5 in 15, so on average 5 × 5/15 = 5/3 are shared. In rows the number must match exactly at each place, chance 1 in 15: 5/15 = 1/3 in all. The hall's columns are as if copied from one another, so they fill together. Rows are nearly independent, and out of 2,500 independent attempts someone wins early.

History

A "bug" that turned out to be maths

Joseph Kisenwether, a Harvey Mudd College graduate, worked for a company that made electronic bingo software. A client complained of a "bug": winning cards were horizontal far too often. Kisenwether made sure the program was fair and the effect real, and told the mathematician Arthur Benjamin about it. Ben Weiss suggested looking at a hall holding every possible card, and in 2017 the three described the paradox in the journal Math Horizons.

In the article they report that the program played 100,000 games on 1,000 cards, and horizontal winners were almost twice as common. Our simulation in round 3 gives the same. For a hall with every card and no free centre they got 75.2% in favour of the row; with a free centre, Kisenwether and Dick Hess found 73.73%.

Theory

35 shapes and Ferrers diagrams

To compute the exact probability, the authors group ball sequences by "shape": how many times each letter came out before the deciding ball. On ball 10, for instance, a row comes from the shapes 4311, 4221, 3321 and 3222 (no free centre): four letters, each 1 to 4 times. A column also comes from exactly four shapes.

This is no accident. Row shapes and column shapes match up through Ferrers diagrams: take one off each part and swap the rows and columns of dots. There are 35 shapes in all, as many as lattice paths in a 4 × 3 grid, that is C(7, 3), and q-binomial coefficients give how the shapes spread over the ball numbers.

Round 5 · Going further

Diagonals, British bingo and the winners of a crowd

Diagonals play by the rules of rows. British bingo sidesteps the paradox by its very rules. And the idea of "a shared bottleneck against personal luck" works far beyond the hall.

The maths

A diagonal is a row that runs at a slant

A diagonal, like a row, takes one number from each column. And both diagonals pass through the free centre, so each needs only four numbers: B, I, G and O. A card has three such "short" lines: two diagonals and the middle row.

On one card there are only two diagonals against ten rows and columns, so they win rarely, in 24% of games. In a hall of 500 cards diagonals catch the same taxi as rows, by an even shorter route: they are in 46% of first wins already. Columns, waiting for five of one letter, fall from 42% to 27%.

The logic

British bingo simply has no columns

In Britain bingo is played with 90 balls. The ticket is 3 × 9: nine columns by tens (1–9, 10–19 and so on up to 90), each row holds five numbers and four blanks, so a column has three numbers at most. Only rows win: one line, two lines and a "full house", all 15 numbers of the ticket. Columns and diagonals are not among the prizes, so there is nothing to compare: the rules simply removed the "one train for all". Tickets are sold in strips of six that together hold all 90 numbers, so whoever holds a strip marks some number on every ball.

In practice

A crowd's winner is selected on personal luck

The rule from bingo: when there are many contestants, the first of them more often wins in the way where contestants' results differ most. What is the same for everyone gives no edge, however many people play.

Bonus · Fun facts

Things to tell your friends

1929

First came the beans

The toy salesman Edwin Lowe saw a game called "beano" at a carnival near Atlanta in late 1929: players covered numbers with beans. As the popular legend goes, when Lowe played it with friends, one player shouted "bingo!" instead of "beano" in her excitement. So Lowe named his version of the game.

6 000

Cards from a mathematician

The story goes that once hundreds of people played at a time, simple cards produced too many winners. So Lowe hired the Columbia University mathematician Carl Leffler, who drew up 6,000 different cards.

5.5 × 10²⁶

How many cards exist

Columns B, I, G, O each have 15 × 14 × 13 × 12 × 11 = 360,360 ordered sets, column N with its free centre 15 × 14 × 13 × 12 = 32,760. In all, 552,446,474,061,128,648,601,600,000 different cards. The hall "with every possible card" from round 4 is purely imaginary.

× 2

Almost twice

Arthur Benjamin, Joseph Kisenwether and Ben Weiss described the paradox in "The Bingo Paradox" (Math Horizons, September 2017, vol. 25, no. 1, pp. 18–21). Their program played 100,000 games on 1,000 cards, and horizontal winners were almost twice as common as vertical ones.

73.73%

The exact number

For a hall with every card and a free centre, the chance that the first line is a row is 73.73% (rounded). Joseph Kisenwether and Dick Hess found it independently; Hess wrote the puzzle book "The Population Explosion and Other Mathematical Puzzles" (World Scientific, 2016). Our exact calculation in round 3 gives the same.

16 balls

The longest game in an endless hall

If the hall holds every possible card, a game lasts no more than 16 balls. For no one to have a row, one of the letters B, I, G, O must not have come out yet; for no one to have a column, the other three came out at most 4 times each and N at most 3. That is 15 balls, and the 16th decides the game. In an ordinary hall of 500 cards the first "Bingo!" comes on ball 13 on average.
