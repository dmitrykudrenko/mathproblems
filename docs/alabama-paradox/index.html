Парадокс Алабами У раді стає на одне місце більше. Чи може район від цього втратити місце?Може: малий район утрачає одне з двох.

Рада ділить місця між трьома районами пропорційно населенню, а дробові частки округлює найпростішим чесним правилом. Місць було 10, стане 11. Здається, що зайве місце може лише комусь додати. Скільки місць тоді отримає найменший район? Зафіксуйте відповідь, а потім перевірте її: покрутіть розмір ради самі, проженіть тисячі випадкових рад і прочитайте пояснення.

Рада ділить місця між районами з 6, 6 і 2 тисячами жителів за методом найбільших залишків. При 10 місцях малий район має 2, а при 11 лише 1, хоч місць більше, а люди ті самі. Нове місце збільшує частку кожного району пропорційно його розміру, і залишки великих районів обганяють залишок малого. 1880 року так у таблиці Бюро перепису Алабама мала 8 місць при Палаті зі 299 і 7 при Палаті з 300.

Умова задачі

Три райони, десять місць

Ділити місця пропорційно легко, доки частки цілі. Але людей не ділять на шматки, тож дроби треба якось округлити. Правило нижче придумав Александер Гамільтон, і воно здається бездоганно чесним.

  1. 1

    Три райони

    У районі А 6 000 жителів, у районі Б теж 6 000, у районі В 2 000. Разом 14 000.

  2. 2

    Чесна частка

    Чесна частка району — це скільки місць йому належало б, якби місця можна було різати: населення району × кількість місць / усе населення. При 10 місцях це 6 000 × 10 / 14 000 ≈ 4,29 для А і Б і 1,43 для В.

  3. 3

    Правило найбільших залишків

    Кожен район спершу отримує цілу частину своєї частки: 4, 4 і 1. Це 9 місць. Місця, що лишилися, роздають по одному районам з найбільшою дробовою частиною. Десяте місце дістається В: у нього 0,43, а в А і Б лише по 0,29. Виходить 4, 4 і 2.

  4. 4

    Питання

    Раду збільшують до 11 місць. Населення не змінилося, правило те саме. Скільки місць тепер отримає район В?

Інтуїція каже

«Місць стало більше, тож нікому не може стати менше. У гіршому разі все лишиться як було»

Насправді В отримує 1 місце замість 2. Частки ростуть: 4,71, 4,71 і 1,57. Цілі частини ті самі, 4, 4 і 1, але тепер лишаються два місця, і обидва забирають великі райони: їхні 0,71 обігнали 0,57 району В.

Що ми припускаємо

  • Населення районів не змінюється, змінюється лише кількість місць.
  • Частки рахують точно, без проміжного округлення.
  • Окремого мінімуму місць на район немає.
  • Рівних залишків у цій задачі не трапляється, тож жереб не потрібен.

Перевірте самі в коді

Та сама симуляція коротко і без бібліотек. JavaScript запускається в консолі браузера (F12) або в Node, Python потребує лише стандартної бібліотеки.

JavaScript
// Випадкові ради: від 2 до 12 районів з населенням від 1 до 100 тисяч, від 10 до 40 місць. Додаємо одне місце: чи втрачає хтось місце?
function largestRemainder(p, h) {
  const P = p.reduce((a, b) => a + b, 0), q = p.map(x => x * h / P), s = q.map(Math.floor);
  const order = p.map((_, i) => i).sort((a, b) => (q[b] - s[b]) - (q[a] - s[a]));
  const left = h - s.reduce((a, b) => a + b, 0);
  for (let k = 0; k < left; k++) s[order[k]]++;            // зайві місця — найбільшим залишкам
  return s;
}
function dHondt(p, h) {                                    // наступне місце — найбільшому p / (s + 1)
  const s = p.map(() => 0);
  for (let k = 0; k < h; k++) { let b = 0; p.forEach((x, i) => { if (x / (s[i] + 1) > p[b] / (s[b] + 1)) b = i; }); s[b]++; }
  return s;
}
console.log('6·6·2 тис.: 10 місць', largestRemainder([6, 6, 2], 10), '11 місць', largestRemainder([6, 6, 2], 11));
const loses = (f, p, h) => { const a = f(p, h), b = f(p, h + 1); return a.some((x, i) => b[i] < x); };
const T = 20000;
for (const n of [2, 3, 4, 6, 8, 12]) {
  let ham = 0, dh = 0;
  for (let t = 0; t < T; t++) {
    const p = Array.from({ length: n }, () => 1 + 99 * Math.random()), h = 10 + Math.floor(31 * Math.random());
    if (loses(largestRemainder, p, h)) ham++;
    if (loses(dHondt, p, h)) dh++;
  }
  console.log('районів', n, '· найбільші залишки', (100 * ham / T).toFixed(1) + '%', '· д\'Ондт', dh);
}
Python
# Випадкові ради: від 2 до 12 районів з населенням від 1 до 100 тисяч, від 10 до 40 місць. Додаємо одне місце: чи втрачає хтось місце?
import math, random

def largest_remainder(p, h):
    P = sum(p)
    q = [x * h / P for x in p]
    s = [math.floor(x) for x in q]
    order = sorted(range(len(p)), key=lambda i: q[i] - s[i], reverse=True)
    for i in order[:h - sum(s)]:                            # зайві місця — найбільшим залишкам
        s[i] += 1
    return s

def d_hondt(p, h):                                          # наступне місце — найбільшому p / (s + 1)
    s = [0] * len(p)
    for _ in range(h):
        s[max(range(len(p)), key=lambda i: p[i] / (s[i] + 1))] += 1
    return s

print("6·6·2 тис.: 10 місць", largest_remainder([6, 6, 2], 10), "11 місць", largest_remainder([6, 6, 2], 11))

def loses(f, p, h):
    a, b = f(p, h), f(p, h + 1)
    return any(y < x for x, y in zip(a, b))

T = 20000
for n in [2, 3, 4, 6, 8, 12]:
    ham = dh = 0
    for _ in range(T):
        p = [1 + 99 * random.random() for _ in range(n)]
        h = random.randint(10, 40)
        ham += loses(largest_remainder, p, h)
        dh += loses(d_hondt, p, h)
    print("районів", n, "· найбільші залишки", f"{100 * ham / T:.1f}%", "· д'Ондт", dh)
Раунд 4 · Пояснення

Залишки великих ростуть швидше

Інтуїція думає про місця, а правило дивиться на дробові залишки. Нове місце додає кожному району шматок, пропорційний його населенню, тож великі отримують більші шматки й обганяють малого в черзі за зайвими місцями.

На пальцяхкартинки, аналогії, маленькі числа

Шар «На пальцях» приховано на всіх задачах.

Перегони залишків

Одне місце, три різні шматки

Це ще не все пояснення, але суть така. Зайві місця дістаються тим, у кого найбільший «хвостик» після цілих. Одне нове місце ділиться між районами як усе інше, пропорційно населенню: А і Б отримують по 6/14 ≈ 0,43 місця, а малий В лише 2/14 ≈ 0,14. Хвостик В майже стоїть, а хвостики великих районів стрибають уперед.

При 10 місцях одне зайве місце, і його бере В з найбільшим хвостиком 0,43. При 11 місцях зайвих два, але хвостики А і Б виросли до 0,71 і обігнали 0,57 району В. Обидва зайві місця йдуть великим, а В лишається з цілою частиною, 1.

Де парадоксу немає

Із двома районами це звичайне округлення

Частки двох районів разом дають ціле число, тож їхні хвостики разом дають або 0, або 1. Зайве місце буває щонайбільше одне, і бере його той, чий хвостик більший за половину. Тобто кожен район просто округлює свою частку до найближчого цілого.

А частка з новим місцем лише росте, тож і округлена частка не може зменшитися. Саме тому в раунді 2 з двома районами рожевих клітинок немає, а в симуляції парадокс з'являється лише від трьох районів.

Строготаблиці, графіки, формули

Шар «Строго» приховано на всіх задачах.

Залишки як пилка

Хвостики районів, коли рада росте від 1 до 21 місця

А і Б: +0,43 за місце В: +0,14 за місце В утрачає місце

Кожна точка — дробова частина частки при h місцях. Коли частка перескакує через ціле, хвостик падає до нуля, тож графік схожий на пилку. Зуби А і Б круті, бо їхня частка росте на 3/7 місця за крок; зуби В пологі, лише 1/7. Пропорція 3 : 3 : 1 повторюється кожні 7 місць, тому В утрачає місце при переходах 3 → 4, 10 → 11, 17 → 18 і далі через кожні сім.

Алгебра

Частка росте на p/P, а не на однакову величину

Хай у районі p жителів, усього P, місць h. Частка q = p · h / P. Додаємо місце: q зростає на p/P, тобто на частку району в населенні. Усі частки ростуть на той самий відсоток, а в абсолютних числах великі ростуть більше.

Сума всіх часток завжди h, тож кількість зайвих місць дорівнює сумі хвостиків. Район утрачає місце, коли його ціла частина не зросла, а кількість районів з більшим хвостиком стала не меншою за кількість зайвих місць. Для цього треба, щоб хтось інший обігнав його в черзі, а обігнати може лише той, чия частка росте швидше, тобто більший район.

Межі частки

Що цей метод гарантує

Найбільші залишки ніколи не дають району менше за округлену вниз частку і більше за округлену вгору. Це «правило квоти»: 1,57 може стати лише 1 або 2, а не 0 чи 3. Порушити монотонність метод може, а вийти за межі частки — ні.

Тож при 11 місцях В з 1 місцем формально в межах: його частка 1,57. Порушено інше: при 10 місцях, коли частка була меншою, 1,43, він мав 2.

Для тих, хто любить формули

Частки, хвостики і черга

Частка району i з населенням pi при h місцях і загальному населенні P, та її ріст від одного нового місця.

qi(h)=pihP,qi(h+1)−qi(h)=piP

Кожен район отримує цілу частину, а зайвих місць k стільки, скільки дають разом дробові частини.

si=⌊qi⌋+[i ∈ top k],k=h−∑j⌊qj⌋=∑j{qj}

Приклад 6, 6, 2 тисячі (P = 14): частки при 10 і 11 місцях.

q(10)=(307,307,107)→(4,4,2),q(11)=(337,337,117)→(5,5,1)

Метод дільників: шукають одне число d і округлюють кожну частку pi/d своїм правилом (д'Ондт — униз, Сент-Лаге — до найближчого). Більше місць означає менше d, тож жодне pi/d не зменшується.

si=round(pid),∑isi=h

Найбільші залишки — це не один дільник для всіх, а окрема черга з хвостиків при кожному h. Черга при h + 1 може виявитися зовсім іншою, ніж при h, і саме тут з'являється парадокс.

Глибшеузагальнення, теорія, історія

Шар «Глибше» приховано на всіх задачах.

Методи дільників

Парадоксу немає, але є інша ціна

Д'Ондт (у США його називали методом Джефферсона), Сент-Лаге (метод Вебстера) і Гантінгтон — Гілл ділять населення кожного району на спільний дільник і округлюють. Їх можна рахувати й послідовно: кожне наступне місце йде району з найбільшим p/(s + 1) у д'Ондта чи p/(2s + 1) у Сент-Лаге, де s — уже отримані місця. Рада з h + 1 місць — це рада з h місць плюс ще одне, тож забрати місце в когось такий метод не може. Ця властивість зветься монотонністю за розміром ради.

Ціна — правило квоти. Чотири райони з 20, 5, 5 і 5 тисячами, 10 місць: частка великого 5,71, а д'Ондт дає йому 7, більше за округлену вгору частку. Найбільші залишки дали б йому 6, у межах частки.

Теорема

Балінскі і Янг: усього одразу не можна

Мішель Балінскі і Пейтон Янг довели, що жоден метод розподілу не може завжди дотримуватися правила квоти й водночас ніколи не давати парадоксу населення (коли район, що росте швидше, утрачає місце на користь того, що росте повільніше). Для чотирьох і більше районів це неможливо в принципі. Вони виклали цю теорію в книжці «Fair Representation» 1982 року.

Тож вибір методу — це вибір, яку несправедливість терпіти. Методи дільників монотонні, але інколи виходять за межі частки. Найбільші залишки тримаються меж, але страждають від парадоксів Алабами, населення і нових штатів (раунд 5).

1880: Палата зі 299 і з 300 місць

Після перепису 1880 року головний клерк Бюро перепису США Чарльз Сітон розрахував розподіл місць у Палаті представників за методом Гамільтона для всіх розмірів від 275 до 350. При 299 місцях Алабама мала 8, а при 300 лише 7. Ми перерахували це з населення 38 штатів за переписом (разом 49 371 340 осіб; Невада отримує обов'язкове за Конституцією 1 місце, хоч її частка 0,38):

При 299 місцях після цілих частин лишалося 20 місць, і Алабама з хвостиком 0,646 взяла останнє, двадцяте, випередивши Іллінойс і Техас з їхніми 0,640. При 300 хвостик Алабами виріс лише на 0,026, Техасу на 0,032, а Іллінойсу на 0,062. Обидва обігнали Алабаму. Водночас частки трьох штатів перескочили через ціле число, тож зайвих місць стало не 20, а 18, і Алабама опинилася дев'ятнадцятою в черзі. Відкриття викликало бурю в Конгресі; 1911 року Палата перейшла на метод Вебстера, а з 1941-го рахує методом Гантінгтона — Гілла.

Раунд 5 · Ускладнюємо

Ще два парадокси, Верховна Рада і Бундестаг

Найбільші залишки можуть покарати район не лише за нове місце, а й за власне зростання чи за появу сусіда. А в реальних виборах цим правилом рахують мандати й досі.

Три парадокси одного методу

1 · Математика

Ріст населення і новий район теж шкодять

Парадокс населення. Район А росте, Б стоїть на місці, а місце переходить від А до Б. Причина та сама: усі частки рахуються від загального населення, а воно росло через третій район, тож хвостики пересортувалися. За Вікіпедією та книжкою Джеймса Стайна, 1900 року Вірджинія так утратила місце на користь Мена, хоч росла швидше.

Парадокс нових штатів. До ради приєднують новий район разом з його чесною часткою місць. Старі райони нічого не віддавали, а місце між ними переходить. 1907 року Оклахома увійшла до США з 5 новими місцями, і перерахунок забрав місце в Нью-Йорка й віддав Мену.

2 · Логіка

Ціле не ділиться на цілі частини чесно в усіх сенсах

Кожна з вимог звучить очевидно: кожен отримує свою частку, округлену вниз чи вгору; більше місць нікого не ображає; хто росте швидше, не втрачає на користь того, хто росте повільніше. Теорема Балінскі — Янга каже, що разом вони несумісні. Це не вада конкретного правила, а властивість самої задачі: дроби не можна округлити так, щоб округлення поводилося як дроби.

Схоже з голосуванням: парадокс Кондорсе показує, що навіть думку більшості не завжди можна скласти в чесний порядок. А частини і ціле, які поводяться по-різному, є ще в парадоксі Сімпсона і феномені Вілла Роджерса, де середні всіх груп ростуть, а люди ті самі.

3 · Практика

Верховна Рада 2019: 225 мандатів за найбільшими залишками

За законом «Про вибори народних депутатів України» 2011 року (ст. 98), за яким обирали Раду 2012, 2014 і 2019 років, 225 мандатів за списками ділять між партіями, що подолали 5%. Виборча квота — це голоси за ці партії, поділені на 225; кожна партія отримує цілу частину від своїх голосів, поділених на квоту, а решту мандатів по одному отримують партії з найбільшими дробовими залишками. Голоси нижче — офіційні результати ЦВК, перевірте самі.

Бундестаг ділив місця між партіями методом Гера — Німаєра, тобто найбільшими залишками, з виборів 1987 року. 2008 року закон замінив його методом Сент-Лаге — Шеперса, щоб уникнути парадоксів, і вперше його застосували на виборах 27 вересня 2009 року. Якщо ділите ціле на цілі частини в таблиці (бюджет між відділами, ноутбуки між командами), а загальна сума може змінитися, беріть метод дільників: зайва одиниця тоді нікому не зменшить частку.

Метод, що діє досі

З 1941 року Палата представників США ділить свої 435 місць між штатами методом Гантінгтона — Гілла. Це метод дільників, і парадоксу Алабами в ньому немає.

Бундестаг змінив правило

Бундестаг з 1987 року ділив місця найбільшими залишками (метод Гера — Німаєра). Через парадокси 2008 року його замінили методом Сент-Лаге — Шеперса, уперше на виборах 2009 року.
