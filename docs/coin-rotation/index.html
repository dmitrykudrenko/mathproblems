Зафіксуйте відповідь, а потім перевірте її: покотіть монету самі, порахуйте на комп'ютері й прочитайте пояснення.

Дві однакові монети лежать на столі. Одну притиснули пальцем, а другу котять навколо неї без ковзання. Обіди однакові, тож здається, що вийде рівно один оберт. Насправді монета повертається двічі: один раз від кочення, і ще раз від того, що сама обходить коло. Той самий «зайвий» оберт ховається в зоряній добі, у Місяці й у планетарних передачах.

Умова задачі

Дві монети, один обхід

Цю задачу можна перевірити за хвилину двома монетами з гаманця. Але спершу спробуйте відповісти подумки: так цікавіше дізнатися, чи збіглася ваша інтуїція з тим, що побачать очі.

  1. 1

    Дві однакові монети

    Дві монети одного розміру лежать на столі впритул одна до одної. Нижню притиснули пальцем, вона не рухається. На верхній намальована стрілка, що дивиться вгору.

  2. 2

    Котимо без ковзання

    Верхню монету котять по ободу нерухомої, як зубчасте колесо по іншому колесу: ободи весь час торкаються і не проковзують один по одному.

  3. 3

    Один повний обхід

    Монету котять, доки вона не обійде нерухому монету й не повернеться на те саме місце, нагору.

  4. 4

    Питання

    Скільки повних обертів зробила рухома монета? Тобто скільки разів її стрілка, якщо дивитися на стіл згори, повернулася на повне коло?

Інтуїція каже

«Обіди однакові, тож монета прокотиться рівно на свою довжину й зробить один оберт»

Насправді обертів два. Кочення по ободу справді дає один оберт. Але монета ще й обходить нерухому монету по колу, і цей обхід сам по собі повертає її ще раз, навіть якби вона зовсім не котилася.

Що ми припускаємо

  • Монети ідеально круглі й однакові, радіус r.
  • Ковзання немає: точка дотику рухомої монети в кожну мить нерухома.
  • Оберти рахуємо відносно стола, як їх побачила б камера над ним.
  • Один оберт — це коли стрілка знову дивиться в той самий бік.

Раунд 2 · Спробуйте самі

Покотіть монету і стежте за стрілкою

Тягніть монету пальцем чи мишею або рухайте повзунок. Блідими копіями лишаються положення після кожної чверті шляху. Потім перемкніться на пряму доріжку такої самої довжини, як обід нерухомої монети, і порівняйте.

Лічильники

«Прокотилася ободом» показує, скільки свого обода монета віддала на дотик: по прямій і навколо монети це однаково, рівно один обід. А оберти відносно стола різні. Різницю дає сам обхід по колу.

Раунд 3 · Обчислення

Монети різних розмірів, зовні й усередині

Комп'ютер замінює нерухоме коло радіуса R на 3600-кутник і котить по ньому монету радіуса r, зовні або всередині кільця. На сторонах монета котиться, на кутах повертається навколо вершини. Оберти рахуються так, як рахувала б камера над столом: за кутом стрілки. Формул тут немає, лише кочення.

Усі відношення

Зовні точки лягають на пряму R/r + 1, усередині на R/r − 1, і жодна не лягає на сіру R/r, яку підказує інтуїція. При R/r = 3, як на іспиті SAT 1982 року (див. факти), виходить 4. Монета, більша за кільце (R/r = ½), у нього не влазить.

Після вашої відповіді тут з'явиться код симуляції, який можна запустити в себе.

Перевірте самі в коді

Та сама симуляція коротко і без бібліотек. JavaScript запускається в консолі браузера (F12) або в Node, Python потребує лише стандартної бібліотеки.

JavaScript
// Монета радіуса 1 котиться без ковзання навколо нерухомої монети радіуса R, зовні та всередині кільця. Скільки обертів зробить стрілка на ній?
// Коло замінено 3600-кутником: на сторонах монета котиться, на кутах повертається навколо вершини.
const N = 3600, r = 1;
function roll(R, inside) {
  const side = 2 * R * Math.sin(Math.PI / N);             // сторона многокутника
  // всередині монета котиться по зсунутому на r многокутнику, а кутів не торкається
  const track = inside ? 2 * (R * Math.cos(Math.PI / N) - r) * Math.tan(Math.PI / N) : side;
  let angle = 0, prev = 0, turns = 0;                       // кут стрілки відносно стола
  for (let i = 0; i < N; i++) {
    angle += (inside ? -1 : 1) * track / r;                 // прокотилася на track: поворот track / r
    if (!inside) angle += 2 * Math.PI / N;                  // поворот навколо вершини
    // рахуємо оберти так, як рахувала б камера над столом: за кутом стрілки
    const a = Math.atan2(Math.sin(angle), Math.cos(angle));
    let d = a - prev; if (d > Math.PI) d -= 2 * Math.PI; if (d < -Math.PI) d += 2 * Math.PI;
    turns += d / (2 * Math.PI); prev = a;
  }
  return Math.abs(turns);
}
for (const R of [1, 2, 3, 4, 6]) {
  console.log('R/r =', R, 'зовні', roll(R, false).toFixed(4), 'формула', R + 1,
    '· всередині', roll(R, true).toFixed(4), 'формула', R - 1);
}
Python
# Монета радіуса 1 котиться без ковзання навколо нерухомої монети радіуса R, зовні та всередині кільця. Скільки обертів зробить стрілка на ній?
# Коло замінено 3600-кутником: на сторонах монета котиться, на кутах повертається навколо вершини.
import math

N, r = 3600, 1.0

def roll(R, inside):
    side = 2 * R * math.sin(math.pi / N)                    # сторона многокутника
    # всередині монета котиться по зсунутому на r многокутнику, а кутів не торкається
    track = 2 * (R * math.cos(math.pi / N) - r) * math.tan(math.pi / N) if inside else side
    angle = prev = turns = 0.0                              # кут стрілки відносно стола
    for _ in range(N):
        angle += (-1 if inside else 1) * track / r          # прокотилася на track: поворот track / r
        if not inside:
            angle += 2 * math.pi / N                        # поворот навколо вершини
        # рахуємо оберти так, як рахувала б камера над столом: за кутом стрілки
        a = math.atan2(math.sin(angle), math.cos(angle))
        d = (a - prev + math.pi) % (2 * math.pi) - math.pi
        turns += d / (2 * math.pi)
        prev = a
    return abs(turns)

for R in [1, 2, 3, 4, 6]:
    print("R/r =", R, "зовні", f"{roll(R, False):.4f}", "формула", R + 1,
          "· всередині", f"{roll(R, True):.4f}", "формула", R - 1)
Раунд 4 · Пояснення

Один оберт від кочення, ще один від обходу

Інтуїція рахує лише кочення: скільки разів обід монети вкладається в обід нерухомої. Але монета ще й рухається по колу, а будь-що, що обходить коло, повертається разом із ним.

На пальцяхкартинки, аналогії, маленькі числа

Шар «На пальцях» приховано на всіх задачах.

Без кочення

Обійдіть стіл, дивлячись на нього

Перевірка на півдорозі

Унизу стрілка знову дивиться вгору

Прокотіть монету на протилежний бік, униз. Вона прокотилася лише половиною свого обода, а стрілка вже знову дивиться вгору: позаду цілий оберт. Отже, за повний обхід буде два.

Чому так? Половина обода повертає монету на пів оберту відносно нерухомої: точка, що спершу торкалася її, тепер на протилежному від неї боці. Але й сама нерухома монета з погляду рухомої тепер з іншого боку, зверху замість знизу. Це ще пів оберту.

Кути замість кола

Навколо трикутника: на сторонах кочення, на кутах поворот

Покотіть монету навколо трикутника. Уздовж кожної сторони вона котиться, як по прямій, і повертається рівно на стільки, скільки сторона займає її обода. А на кожному куті монета не котиться, а повертається навколо вершини, як двері на завісі. Три такі повороти (рожеві дуги) разом дають рівно один повний оберт, бо, обійшовши фігуру, монета знову дивиться тим самим боком до неї.

Коло схоже на многокутник з дуже великою кількістю дуже малих кутів. Кути там непомітні, але разом вони так само дають свій один оберт. Так і рахує комп'ютер у раунді 3.

Строготаблиці, графіки, формули

Шар «Строго» приховано на всіх задачах.

Шлях центру

Центр іде колом радіуса R + r

Котячись по прямій, монета повертається на один оберт щоразу, як її центр проходить 2πr, довжину обода. Те саме правило діє й на опуклому шляху: кут повороту дорівнює довжині шляху центру, поділеній на r. На кутах трикутника центр іде маленькою дугою радіуса r, і поворот там теж «шлях / r».

Навколо монети радіуса R центр рухомої монети йде колом радіуса R + r. Його довжина 2π(R + r). Ділимо на обід 2πr і отримуємо (R + r)/r = R/r + 1 обертів. Для однакових монет центр іде колом радіуса 2r, тобто вдвічі довшим за обід: 2 оберти.

Усередині кільця

Тут обхід віднімає оберт

Тепер монета котиться по внутрішньому боці кільця радіуса R. Її центр іде колом радіуса R − r, тож обертів (R − r)/r = R/r − 1. Обхід і далі дає один оберт, але кочення по внутрішньому боці крутить монету в протилежний бік, тож оберти віднімаються.

У кільці вдвічі більшому за монету виходить лише 1 оберт, хоч обід кільця дорівнює двом ободам монети. А в кільці такого самого розміру монета просто стоїть: 1 − 1 = 0. Зовні оберт додається, всередині віднімається, а кочення в обох випадках однакове, R/r.

Для тих, хто любить формули

Кочення плюс обхід

Зовні: центр рухомої монети проходить коло радіуса R + r, а кожні 2πr шляху дають один оберт.

Nзовні=2π(R+r)2πr=Rr+1,R=r:N=2

Усередині кільця: центр іде колом радіуса R − r, і монета крутиться в протилежний бік.

Nвсередині=2π(R−r)2πr=Rr−1

Те саме як сума двох частин: кочення по ободу довжини 2πR і поворот лінії, що з'єднує центри монет, на повне коло.

N=2πR2πr⏟кочення±1⏟обхід

Будь-яка опукла фігура з периметром P: на сторонах кочення, на кутах повороти, які разом дають 2π.

N=P2πr+1

Інтуїція бере лише перший доданок, R/r. Він справді рахує, скільки разів обід монети вкладається в обід нерухомої. Другий доданок не залежить ні від розмірів, ні від форми: це один повний поворот напрямку на центр за один обхід.

Системи відліку

Відносно стола два, відносно нерухомої монети один

«Скільки обертів» має сенс лише разом з «відносно чого». Уявіть мураху, що сидить на нерухомій монеті й весь час дивиться на рухому. Для неї рухома монета повертається рівно R/r разів, як і обіцяє інтуїція: мураха сама обертається разом з лінією між центрами. Камера над столом стоїть на місці й бачить ще й цей поворот лінії, один на обхід.

Кутові швидкості в різних системах відліку додаються: оберти відносно стола = оберти відносно лінії центрів + оберти самої лінії. Інтуїція помиляється не в арифметиці, а в тому, що непомітно рахує в системі мурахи, хоча питання стосується стола. Ту саму різницю на один оберт астрономи бачать між зоряною і сонячною добою (раунд 5).

Теорія й історія

Дотична обертається один раз, а колесо Аристотеля ковзає

Чому «обхід» дає рівно один оберт для будь-якої опуклої фігури? Бо дотична до простої замкненої кривої, обійшовши її, повертається рівно на 360°. Для гладких кривих це строго довів Гайнц Гопф 1935 року (теорема про оберт дотичної, Umlaufsatz). Для многокутника це звична шкільна сума зовнішніх кутів, 360°.

А «без ковзання» в умові важливе. Давня «Механіка», яку приписують Аристотелю, описує колесо з двома ободами різних радіусів на одній осі: за один оберт великий обід прокочується на свою довжину, але й малий проходить ту саму відстань, хоч він коротший. Розгадка в тому, що малий обід не котиться чисто, а частково ковзає. Галілей розбирав цей парадокс у «Бесідах і математичних доведеннях» 1638 року.

Раунд 5 · Ускладнюємо

Будь-яка форма, Земля і шестерні

«Плюс один оберт за обхід» не залежить від форми, переходить на небо і працює в коробках передач. А точка на ободі монети малює криві з власними іменами.

Математика

P/(2πr) + 1 для будь-якої опуклої фігури

Квадрат, трикутник і монета з однаковим периметром, рівним ободу рухомої монети, дають однакові 2 оберти: один від кочення по периметру, один від обходу. Форма впливає лише на те, де саме монета повертається: на кутах рвучко, на колі рівномірно.

Точка на ободі монети, що котиться зовні кола, малює епіциклоїду з R/r вістрями. При R = r це кардіоїда, «серце» з одним вістрям; при R = 2r нефроїда, «нирка» з двома, таку криву світло малює на дні чашки. Усередині кільця виходять гіпоциклоїди: при R = 3r дельтоїда, при R = 4r астроїда, а при R = 2r точка ходить по прямій. Цю «пару Тусі» описав перський астроном Насир ад-Дін ат-Тусі 1247 року.

Земля — монета, що «котиться» навколо Сонця. Відносно далеких зірок вона обертається за 23 год 56 хв 4 с. Але за цей час вона просувається орбітою, і щоб Сонце знову стало в зеніті, треба довернутися ще приблизно на 4 хвилини. За рік ці хвилини складаються в цілий оберт: відносно зірок Земля обертається приблизно 366,24 раза, а сонячних діб лише 365,24. Земля крутиться в той самий бік, у який обходить Сонце, тож обхід віднімає одну добу, як у монети всередині кільця.

Місяць завжди повернутий до Землі одним боком, тобто відносно лінії «Земля — Місяць» не обертається зовсім. Та відносно зірок він робить один оберт за кожен обхід, раз на 27,32 доби. За рік це 13,37 оберта, а повних змін фаз (від молодика до молодика, 29,53 доби) на одну менше, 12,37, бо Земля з Місяцем самі обходять Сонце. Щоразу різниця на одиницю виникає з одного: рахуємо оберти в різних системах відліку.

Планетарні передачі: монети з зубцями

Зубці — це «без ковзання» в металі. Посередині сонячна шестерня, навколо неї котяться сателіти на водилі, а все обіймає зовнішній вінець із зубцями всередині. Числа в таблиці перевіряються формулою Вілліса: (ωсонце − ωводило) / (ωвінець − ωводило) = −zвінець/zсонце, де z — кількість зубців.
