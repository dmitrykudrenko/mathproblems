Парадокс берегової лінії Крок циркуля вдвічі коротший. На скільки довшим стане берег?Приблизно на 19 %, і так щоразу.

Західне узбережжя Великої Британії міряють на детальній карті циркулем: ніжки розведені на 100 км за масштабом, і циркуль крокує вздовж берега. Потім розводять ніжки на 50 км і проходять той самий берег ще раз. На скільки відсотків довшим вийде берег у другому вимірі? Зафіксуйте відповідь, а потім перевірте: пройдіть острів циркулем самі, подивіться на графік Річардсона і прочитайте пояснення.

Західне узбережжя Великої Британії міряють циркулем із кроком 100 км, а потім 50 км. Здається, що берег має якусь свою довжину і другий вимір лише трохи її уточнить. Насправді за даними Льюїса Фрая Річардсона кожне вкорочення кроку вдвічі додає приблизно 19 %, і довжина не наближається до жодного числа. Кожна затока має свої менші затоки, і коротший крок заходить у них щоразу.

Умова задачі

Один берег, два циркулі

Так міряють довжину на карті вже кілька століть: циркуль крокує вздовж лінії, а кроки множать на їхню довжину. Спробуйте спершу відповісти подумки, а потім пройдіть берег самі.

  1. 1

    Детальна карта

    На столі велика детальна карта західного узбережжя Великої Британії, з усіма затоками, мисами й скелями, які можна на ній розгледіти.

  2. 2

    Крок 100 км

    Ніжки циркуля розводять на 100 км за масштабом карти. Одну ставлять на берег, другу переносять уперед, теж на берег, і так крок за кроком до кінця узбережжя. Довжина берега дорівнює кількості кроків, помноженій на 100 км.

  3. 3

    Крок 50 км

    Потім ніжки зводять удвічі, до 50 км, і проходять той самий берег так само ретельно.

  4. 4

    Питання

    На скільки відсотків довшим вийде берег у другому вимірі, ніж у першому?

Інтуїція каже

«Берег має свою довжину. Коротший крок трохи точніше обійде вигини: відсоток-два, і далі майже нічого не зміниться»

Насправді берег стає довшим приблизно на 19 %. І з кроком 25 км він знову виросте приблизно на стільки ж, і з кроком 12,5 км теж. Так поводиться не кожна лінія: коло чи пряма дорога майже не змінюються. А берег щоразу відкриває коротшому кроку нові затоки.

Що ми припускаємо

  • Карта достатньо детальна: її дрібні вигини менші за обидва кроки.
  • Обидві ніжки циркуля завжди стають точно на берегову лінію.
  • Кроки рахують чесно, від початку до кінця узбережжя, без пропусків.
  • Порівнюємо дві довжини: кроків × 100 км і кроків × 50 км.

Підказки

Важко вирішити? Відкривайте підказки по одній: спочатку легка, далі сильніша.

  1. 1

    Порівняйте, що робить удвічі коротший крок на прямому шматку берега і біля вузької затоки, яку довгий крок перескакує навпростець.

  2. 2

  3. 3

    Якщо кожна затока має менші затоки, схожі на неї, то кожне вкорочення кроку знаходить нові вигини в тій самій пропорції. Довжина тоді множиться щоразу на те саме число.

Раунд 3 · Симуляція

Графік Річардсона: десятки островів і коло

Комп'ютер будує по 12 випадкових островів двох видів: гладкіші й звивистіші, приблизно як береги, що їх міряв Річардсон. Кожен острів він проходить циркулем із сімома кроками, від 200 км до 3 км, а також круглий острів радіуса 400 км. На графіку обидві осі логарифмічні: кожна поділка множить, а не додає.

Середні довжини

Коло швидко виходить на 2π · 400 ≈ 2513 км і далі стоїть. Острови не зупиняються: їхні точки лягають на прямі, що йдуть угору ліворуч. Нахил прямої і є 1 − D. Для окремого острова приріст від кроку до кроку стрибає, як і в справжніх вимірах, але в середньому тримається сталим. Середнє тут геометричне, бо множники, а не доданки.

Перевірте самі в коді

Та сама симуляція коротко і без бібліотек. JavaScript запускається в консолі браузера (F12) або в Node, Python потребує лише стандартної бібліотеки.

JavaScript
// Випадкові острови з фрактальною розмірністю D: кожна сторона стає 4 копіями довжини r з горбом у море чи в суходіл, 4 · r^D = 1.
// Кожен острів проходимо циркулем із різними кроками й порівнюємо приріст довжини із законом Річардсона 2^(D−1).
const KM = 400, D = 1.25, ISLANDS = 100, STEPS = [100, 50, 25, 12.5];
function island(D) {
  const r = Math.pow(4, -1 / D), hb = (1 - 2 * r) / 2, h = Math.sqrt(r * r - hb * hb);
  let P = [];
  for (let i = 0; i < 7; i++) { const a = 2 * Math.PI * i / 7 + (Math.random() - .5) * .5, rad = 1 + (Math.random() - .5) * .45; P.push([Math.cos(a) * rad, Math.sin(a) * rad]); }
  for (let d = 0; d < 5; d++) {
    const Q = [];
    for (let i = 0; i < P.length; i++) {
      const A = P[i], B = P[(i + 1) % P.length], ux = B[0] - A[0], uy = B[1] - A[1], s = Math.random() < .5 ? 1 : -1;
      Q.push(A, [A[0] + r * ux, A[1] + r * uy], [A[0] + .5 * ux + s * h * uy, A[1] + .5 * uy - s * h * ux], [A[0] + (1 - r) * ux, A[1] + (1 - r) * uy]);
    }
    P = Q;
  }
  return P;
}
// циркуль: наступна ніжка стає туди, де берег уперше виходить з кола радіуса eps навколо попередньої
function measure(P, eps) {
  const n = P.length; let cx = P[0][0], cy = P[0][1], i = 0, steps = 0;
  for (;;) {
    let k = i;
    for (; k < n; k++) { const B = P[(k + 1) % n]; if ((B[0] - cx) ** 2 + (B[1] - cy) ** 2 >= eps * eps) break; }
    if (k === n) return steps * eps + Math.hypot(P[0][0] - cx, P[0][1] - cy);
    const A = k === i ? [cx, cy] : P[k], B = P[(k + 1) % n], ex = B[0] - A[0], ey = B[1] - A[1], fx = A[0] - cx, fy = A[1] - cy;
    const a = ex * ex + ey * ey, b = 2 * (ex * fx + ey * fy), c = fx * fx + fy * fy - eps * eps;
    const t = (-b + Math.sqrt(Math.max(0, b * b - 4 * a * c))) / (2 * a);
    cx = A[0] + t * ex; cy = A[1] + t * ey; i = k; steps++;
  }
}
const logs = STEPS.map(() => 0);
for (let j = 0; j < ISLANDS; j++) {
  const P = island(D);
  STEPS.forEach((e, i) => { logs[i] += Math.log(measure(P, e / KM) * KM) / ISLANDS; });
}
STEPS.forEach((e, i) => console.log('крок', e, 'км: середня довжина', Math.exp(logs[i]).toFixed(0),
  i ? ', приріст +' + (100 * (Math.exp(logs[i] - logs[i - 1]) - 1)).toFixed(1) + '%' : ''));
const per = Math.exp((logs[STEPS.length - 1] - logs[0]) / (STEPS.length - 1));
console.log('Удвічі коротший крок, у середньому: ×' + per.toFixed(3), 'закон Річардсона 2^(D−1) =', Math.pow(2, D - 1).toFixed(3));
// для порівняння коло радіуса 400 км: довжина виходить на 2πr
const C = Array.from({ length: 4096 }, (_, i) => [Math.cos(2 * Math.PI * i / 4096), Math.sin(2 * Math.PI * i / 4096)]);
console.log('Коло, кроки 100 і 50 км:', (measure(C, 100 / KM) * KM).toFixed(1), (measure(C, 50 / KM) * KM).toFixed(1), '2πr =', (2 * Math.PI * KM).toFixed(1));

# Випадкові острови з фрактальною розмірністю D: кожна сторона стає 4 копіями довжини r з горбом у море чи в суходіл, 4 · r^D = 1.
# Кожен острів проходимо циркулем із різними кроками й порівнюємо приріст довжини із законом Річардсона 2^(D−1).
import math, random

KM, D, ISLANDS, STEPS = 400, 1.25, 100, [100, 50, 25, 12.5]

def island(D):
    r = 4 ** (-1 / D)
    hb = (1 - 2 * r) / 2
    h = math.sqrt(r * r - hb * hb)
    P = []
    for i in range(7):
        a = 2 * math.pi * i / 7 + (random.random() - .5) * .5
        rad = 1 + (random.random() - .5) * .45
        P.append((math.cos(a) * rad, math.sin(a) * rad))
    for _ in range(5):
        Q = []
        for i, A in enumerate(P):
            B = P[(i + 1) % len(P)]
            ux, uy = B[0] - A[0], B[1] - A[1]
            s = 1 if random.random() < .5 else -1
            Q += [A, (A[0] + r * ux, A[1] + r * uy), (A[0] + .5 * ux + s * h * uy, A[1] + .5 * uy - s * h * ux),
                  (A[0] + (1 - r) * ux, A[1] + (1 - r) * uy)]
        P = Q
    return P

# циркуль: наступна ніжка стає туди, де берег уперше виходить з кола радіуса eps навколо попередньої
def measure(P, eps):
    n = len(P)
    cx, cy = P[0]
    i = steps = 0
    while True:
        k = i
        while k < n:
            B = P[(k + 1) % n]
            if (B[0] - cx) ** 2 + (B[1] - cy) ** 2 >= eps * eps:
                break
            k += 1
        if k == n:
            return steps * eps + math.hypot(P[0][0] - cx, P[0][1] - cy)
        A = (cx, cy) if k == i else P[k]
        B = P[(k + 1) % n]
        ex, ey, fx, fy = B[0] - A[0], B[1] - A[1], A[0] - cx, A[1] - cy
        a, b, c = ex * ex + ey * ey, 2 * (ex * fx + ey * fy), fx * fx + fy * fy - eps * eps
        t = (-b + math.sqrt(max(0, b * b - 4 * a * c))) / (2 * a)
        cx, cy = A[0] + t * ex, A[1] + t * ey
        i, steps = k, steps + 1

logs = [0.0] * len(STEPS)
for _ in range(ISLANDS):
    P = island(D)
    for i, e in enumerate(STEPS):
        logs[i] += math.log(measure(P, e / KM) * KM) / ISLANDS
for i, e in enumerate(STEPS):
    grow = f", приріст +{100 * (math.exp(logs[i] - logs[i - 1]) - 1):.1f}%" if i else ""
    print("крок", e, "км: середня довжина", f"{math.exp(logs[i]):.0f}", grow)
per = math.exp((logs[-1] - logs[0]) / (len(STEPS) - 1))
print("Удвічі коротший крок, у середньому:", f"×{per:.3f}", "закон Річардсона 2^(D−1) =", f"{2 ** (D - 1):.3f}")
# для порівняння коло радіуса 400 км: довжина виходить на 2πr
C = [(math.cos(2 * math.pi * i / 4096), math.sin(2 * math.pi * i / 4096)) for i in range(4096)]

Раунд 4 · Пояснення

Коротший крок знаходить нові затоки

Інтуїція уявляє берег гладкою лінією, яку циркуль лише трохи «зрізає» на поворотах. Але справжній берег зламаний на всіх масштабах: у затоці є менші затоки, у них бухти, біля бухт скелі. Кожен коротший крок обходить те, що довший перестрибував.

Строготаблиці, графіки, формули

Шар «Строго» приховано на всіх задачах.

Степеневий закон

L(ε) ≈ M · ε1−D

Річардсон наносив на графік довжини, виміряні різними кроками ε, і знайшов, що для кожного берега чи кордону вони лягають на закон L(ε) ≈ M · ε1−D, де M і D — сталі цієї лінії. Для кола D = 1, і довжина від кроку не залежить. Що більше D, то сильніше довжина росте з вкороченням кроку.

Крок удвічі коротший множить довжину на (½)1−D = 2D−1, яким би не був сам крок. Тому приріст однаковий і від 100 до 50 км, і від 50 до 25 км:

Значення D з даних Річардсона, як їх наводить Мандельброт у статті 1967 року.

Як читати графік

На логарифмічних осях закон стає прямою

Логарифм перетворює множення на додавання: log L = log M + (1 − D) · log ε. Тому на осях, де кожна поділка множить на те саме число, степеневий закон стає прямою з нахилом 1 − D. Для кола нахил 0, для заходу Британії −0,25. Звідси й рецепт Річардсона: виміряй берег кількома кроками, проведи пряму через точки, D = 1 − нахил.

Пряма не має межі зверху: якби закон для Британії тримався аж до кроку 1 м, берег вийшов би приблизно в 17,8 раза довшим, ніж із кроком 100 км. На практиці закон перевіряють лише на тих масштабах, де виміряні точки справді лежать на прямій.

Фрактальна розмірність

Між лінією і площею

Відрізок складається з 2 половинок, кожна вдвічі менша: 2 · (½)1 = 1, розмірність 1. Квадрат складається з 4 квадратиків, кожен удвічі менший: 4 · (½)2 = 1, розмірність 2. Крива Коха складається з 4 копій, кожна втричі менша: 4 · (⅓)D = 1 дає D = log 4 / log 3 ≈ 1,26. Ця крива «більша» за лінію, але «менша» за площу.

Острови на цій сторінці збудовані так само: кожна сторона замінюється 4 копіями, кожна в 0,33 раза менша, і кожна копія опуклістю в море чи в суходіл навмання. Довжину копії підібрано так, щоб 4 · 0,33D = 1 при D = 1,25. Справжній берег не має точної самоподібності, лише статистичну: шматок у середньому так само звивистий, як і ціле. Мандельброт назвав такі об'єкти фракталами 1975 року.

Річардсон і Мандельброт

Від суперечки про кордон до нової геометрії

Льюїс Фрай Річардсон, метеоролог і квакер, шукав, чи залежить імовірність війни між сусідами від довжини їхнього спільного кордону. Збираючи дані, він побачив, що довідники різних країн дають для тих самих кордонів дуже різні довжини: для кордону Іспанії й Португалії 987 і 1214 км. Він переміряв береги й кордони різними кроками і знайшов степеневий закон. Річардсон помер 1953 року, а статтю надрукували 1961-го, як додаток до його «Статистики смертельних сварок».

Ці графіки майже ніхто не помітив, доки Бенуа Мандельброт не прочитав у них розмірність D і не надрукував 1967 року в Science статтю «Яка довжина берега Британії?». 1982 року вийшла його книжка «Фрактальна геометрія природи», і слово «фрактал» стало звичним.

Раунд 5 · Ускладнюємо

Сніжинка, масштаб і довідники

Ідеальний берег математики будують за правилом, і в нього нескінченний периметр навколо скінченної площі. А для справжніх берегів висновок простий: довжина без кроку виміру — це не число.

Математика

Нескінченний периметр, скінченна площа

Гельге фон Кох 1904 року описав криву без дотичної в жодній точці. На кожному кроці середню третину кожної сторони замінюють двома сторонами трикутника: сторін стає вчетверо більше, кожна втричі коротша, тож периметр множиться на 4/3. Після n кроків він (4/3)n від початкового і росте без межі. А площа прямує до 8/5 площі трикутника: нові трикутнички щоразу менші, і їхня сума — геометрична прогресія.

Для сніжинки «берег» Річардсона точний: крок утричі коротший дає рівно 4/3 довжини, тобто ε1−D з D = log 4 / log 3. Для справжніх берегів D частіше оцінюють підрахунком клітинок: накривають карту сіткою з кроком s і рахують клітинки, які зачіпає берег. Їх стає приблизно s−D.

Обидва числа правильні, бо це відповіді на різні питання. «Довжина берега» без кроку виміру — як «швидкість» без указівки, за який час її рахували: за годину поїздки й за секунду обгону вийдуть різні числа. Порівнювати можна лише довжини, виміряні однаковим кроком, а для «скільки берега має країна» корисніше D, бо воно від кроку не залежить.

Те саме з GPS-треком пробіжки: годинник ставить точку раз на кілька секунд, і це його крок циркуля. Що частіше точки, то більше дрібних поворотів (і дрібного тремтіння самого GPS) потрапляє в суму, і той самий маршрут показує довшу дистанцію.
