Парадокс Кондорсе Троє друзів голосують парами. Чи важить порядок?Перемагає те, що голова притримав до кінця.

Оля, Марко й Ірина винаймають квартиру разом і обирають, що замовити на вечерю: піцу, суші чи вареники. Вирішують чесно, більшістю голосів, парами: дві страви змагаються, а переможниця виходить у фінал проти третьої. Ви головуєте й вирішуєте лише одне: які дві страви йдуть першими. Скількох із трьох страв ви можете зробити переможницею самим лише порядком голосувань?

Усі три. Більшість ставить піцу вище за суші, суші вище за вареники, а вареники вище за піцу. Це коло, як у грі «камінь, ножиці, папір»: кожна страва програє якійсь іншій. Хоч яку пару пустити першою, переможницю першого раунду б'є страва, яка чекала. Тож голова обирає переможця, коли вирішує, кого притримати до фіналу.

Умова задачі

Троє друзів, три страви, двоє голосувань

Цю задачу описав маркіз де Кондорсе 1785 року, коли шукав, як збори можуть ухвалювати рішення справедливо. Нижче вона в найменшому вигляді: троє людей і три варіанти.

  1. 1

    Смаки

    Кожен упорядкував три страви від найбажанішої до найменш бажаної. Ці списки праворуч, і впродовж вечора вони не змінюються.

  2. 2

    Правило

    Голосують парами. Дві страви змагаються, і кожен голосує за ту, яка в його списку вище. Перемагає та, за яку щонайменше двоє з трьох. Переможниця виходить у фінал проти третьої страви, і переможниця фіналу їде до них на вечерю.

  3. 3

    Ви голова

    Ви не голосуєте й не вмовляєте. Ви лише оголошуєте, які дві страви змагаються першими, а яка чекає фіналу.

  4. 4

    Питання

    Скількох із трьох страв ви можете зробити переможницею, обираючи лише порядок голосувань?

Більшість — найпростіше й найчесніше правило. Але чи завжди вона знає, чого хоче?

Що ми припускаємо

  • Кожен голосує чесно, за свій список, і не хитрує.
  • Списки не змінюються між голосуваннями.
  • Нічиїх немає: голосів троє.

Перевірте самі в коді

Та сама симуляція коротко і без бібліотек. JavaScript запускається в консолі браузера (F12) або в Node, Python потребує лише стандартної бібліотеки.

JavaScript
// Кожен виборець ранжує m варіантів випадково й чесно. Як часто жоден варіант не перемагає всі інші в парних голосуваннях?
function noWinner(m, n, trials) {
  let cycles = 0;
  for (let t = 0; t < trials; t++) {
    const wins = Array.from({ length: m }, () => Array(m).fill(0));   // wins[i][j]: скільки людей ставлять i вище за j
    for (let v = 0; v < n; v++) {
      const order = [...Array(m).keys()];
      for (let i = m - 1; i > 0; i--) { const j = Math.floor(Math.random() * (i + 1)); [order[i], order[j]] = [order[j], order[i]]; }
      for (let a = 0; a < m; a++) for (let b = a + 1; b < m; b++) wins[order[a]][order[b]]++;
    }
    // переможець Кондорсе має більшість проти кожного суперника
    const hasWinner = wins.some((row, i) => row.every((w, j) => j === i || 2 * w > n));
    if (!hasWinner) cycles++;
  }
  return cycles / trials;
}
const exact3 = { 3: 1 / 18, 5: 5 / 72, 7: 875 / 11664, 101: 0.086901 };
for (const n of [3, 5, 7, 101]) {
  console.log('варіантів: 3, виборців:', n, '→ без переможця', (100 * noWinner(3, n, 20000)).toFixed(2) + '%', 'точно', (100 * exact3[n]).toFixed(2) + '%');
}
console.log('Межа для безлічі виборців (Ґільбо):', (100 * (1 / 4 - 3 / (2 * Math.PI) * Math.asin(1 / 3))).toFixed(2) + '%');
for (const m of [4, 5, 10]) {
  console.log('варіантів:', m + ',', 'виборців: 101 → без переможця', (100 * noWinner(m, 101, 4000)).toFixed(1) + '%');
}
Python
# Кожен виборець ранжує m варіантів випадково й чесно. Як часто жоден варіант не перемагає всі інші в парних голосуваннях?
import math, random

def no_winner(m, n, trials):
    cycles = 0
    for _ in range(trials):
        wins = [[0] * m for _ in range(m)]   # wins[i][j]: скільки людей ставлять i вище за j
        for _ in range(n):
            order = random.sample(range(m), m)
            for a in range(m):
                for b in range(a + 1, m):
                    wins[order[a]][order[b]] += 1
        # переможець Кондорсе має більшість проти кожного суперника
        has_winner = any(all(j == i or 2 * wins[i][j] > n for j in range(m)) for i in range(m))
        if not has_winner:
            cycles += 1
    return cycles / trials

exact3 = {3: 1 / 18, 5: 5 / 72, 7: 875 / 11664, 101: 0.086901}
for n in [3, 5, 7, 101]:
    print("варіантів: 3, виборців:", n, "→ без переможця", f"{100 * no_winner(3, n, 20000):.2f}%", "точно", f"{100 * exact3[n]:.2f}%")
print("Межа для безлічі виборців (Ґільбо):", f"{100 * (1 / 4 - 3 / (2 * math.pi) * math.asin(1 / 3)):.2f}%")
for m in [4, 5, 10]:
    print("варіантів:", f"{m},", "виборців: 101 → без переможця", f"{100 * no_winner(m, 101, 4000):.1f}%")
Раунд 4 · Пояснення

Більшість, яка ходить по колу

Кожен із трьох друзів знає, чого хоче: його список послідовний. А от «більшість» — це щоразу інші двоє людей, і разом їхні рішення замикаються в коло.

На пальцяхкартинки, аналогії, маленькі числа

Шар «На пальцях» приховано на всіх задачах.

Камінь, ножиці, папір

Кожна страва програє якійсь іншій

Стрілка веде від переможця до переможеного. Піцу вище за суші ставлять Оля й Ірина, суші вище за вареники — Оля й Марко, вареники вище за піцу — Марко й Ірина. Кожна з трьох більшостей чесна, але це три різні пари людей, і разом вони дають коло.

Ця картка пояснює головне, але ще не все: чому саме голова обирає переможця, розповідає наступна.

Фінал

Хто чекає, той і перемагає

Нехай вареники чекають, а першими йдуть піца й суші. Піца перемагає суші. Але піцу в колі б'є саме та страва, що чекала: вареники. І так з будь-якою парою: переможниця першого раунду — це завжди та страва, яку б'є третя.

Чекає фіналуПерший раундПереможець

Отже, голова не вгадує й не вмовляє. Він просто обирає, кого притримати до кінця.

Окремо й разом

Кожен послідовний, а група ні

Якщо Оля любить піцу більше за суші, а суші більше за вареники, то й піцу вона любить більше за вареники. Так влаштована кожна людина. Здається, що й «воля більшості» має так поводитися. Але більшість — не людина: у кожній парі її складають інші люди. Кондорсе помітив, що навіть коли кожен голосує зв'язно, загальний результат може виявитися незв'язним.

Буває й інакше. Якщо одна страва перемагає кожну іншу один на один, її називають переможцем Кондорсе. Тоді порядок не важить: вона виграє будь-яке голосування, хоч першою, хоч останньою. Влада голови з'являється лише там, де такого переможця немає.

Строготаблиці, графіки, формули

Шар «Строго» приховано на всіх задачах.

Порахуйте

12 компаній з 216

Список з трьох страв можна скласти 3 · 2 · 1 = 6 способами. Троє людей дають 6 · 6 · 6 = 216 різних компаній. Коло буває лише тоді, коли кожна страва стоїть у когось першою, у когось другою й у когось третьою, і списки йдуть «по колу», як у наших друзів.

Напрямків кола два: піца → суші → вареники → піца або навпаки. У кожному три списки, які можна роздати трьом людям 3 · 2 · 1 = 6 способами. Разом 2 · 6 = 12 компаній з колом, тобто 12/216 = 1/18 ≈ 5,6%. В інших 204 є переможець Кондорсе.

Для тих, хто любить формули

Фінал, підрахунок і межа

Коло: x перемагає y, y перемагає z, z перемагає x. Перший раунд між x і y виграє x, а x програє z. Переможець порядку голосувань — завжди той, хто чекав.

x≻y≻z≻x⇒(x:y)→x,(x:z)→z

Троє виборців, три варіанти: два напрямки кола, шість способів роздати три списки.

Глибшеузагальнення, теорія, історія

Шар «Глибше» приховано на всіх задачах.

Теорема Ерроу

Ідеального правила немає

Може, винна саме парна схема, і треба просто взяти інше правило? Кеннет Ерроу 1951 року довів, що ні. Нехай правило перетворює списки виборців на спільний список і виконує три вимоги: якщо всі ставлять x вище за y, то й група теж; порядок x і y в спільному списку залежить лише від того, як люди ставлять x і y; немає диктатора, чий список завжди стає спільним. Для трьох і більше варіантів такого правила не існує.

Парадокс Кондорсе — найменший приклад того, що ламається: парна більшість задовольняє всі три вимоги, але не завжди дає список, бо ходить по колу.

Одна вісь

Коли кола не буває

Дункан Блек 1948 року знайшов важливий виняток. Нехай варіанти можна розставити на одній осі, скажімо, податок від низького до високого, і кожен виборець має на ній улюблену точку, а що далі від неї, то гірше. Тоді кола не буває, а переможцем Кондорсе стає улюблений варіант медіанного виборця. На цьому стоїть і задача про морозиво на пляжі.

Наші страви на одну вісь не ставляться: кожна з них у когось остання. Хоч яку страву поставити посередині, хтось ставить її на останнє місце, тобто любить обидва краї більше за середину.

Історія

Від Льюля до Ерроу

Ще в XIII столітті філософ Рамон Льюль описував вибори для монастирів через порівняння кандидатів попарно. Маркіз де Кондорсе 1785 року в «Есеї про застосування аналізу до ймовірності рішень, ухвалених більшістю голосів» запропонував обирати того, хто перемагає кожного суперника один на один, і сам показав, що такого кандидата може не бути. Чарлз Доджсон, відомий як Льюїс Керролл, 1876 року в брошурі про голосування для оксфордського коледжу розбирав такі кола й пропонував, якщо вони не зникають, не обирати нікого. Його брошури забули майже на століття, доки їх не передрукував Дункан Блек. А Кеннет Ерроу перетворив це спостереження на теорему і 1972 року отримав Нобелівську премію з економіки разом із Джоном Гіксом.

Раунд 5 · Ускладнюємо

Більше варіантів, інші правила, справжній парламент

З кожним новим варіантом коло трапляється частіше. Інші правила підрахунку не рятують. А порядок голосувань у парламентах колись уже поховав закон, який мав більшість.

Турнір більшостей

Математика

Голова обирає серед верхнього кола

Коли варіантів більше, голова ставить їх у чергу: перші двоє змагаються, переможець виходить проти наступного, і так до кінця. Натисніть на варіант на схемі, і сторінка знайде чергу, яка робить його переможцем, або скаже, що такої немає.

Переможцем можна зробити рівно ті варіанти, що входять у «верхнє коло»: найменшу групу, кожен член якої перемагає всіх поза нею. Якщо є переможець Кондорсе, ця група складається з нього одного. У симуляції з 1001 виборцем і випадковими списками переможця Кондорсе немає приблизно у 17,5% виборів з 4 варіантами, у 25% з 5, у 31% з 6 і в 49% з 10.

Коли варіантів безліч, наприклад податок і бюджет водночас, а переможця Кондорсе немає, Річард Маккелві 1976 року довів більше: ланцюжком чесних голосувань «більшістю» голова може довести збори від будь-якого варіанта до будь-якого іншого.

Дев'ять друзів обирають поїздку

Логіка

«Перемагає» не означає «кращий»

Ми звикли, що «вище за» діє ланцюжком: якщо x вище за y, а y вище за z, то x вище за z. Для зросту, ваги чи одного списку смаків так і є. Але «більшість віддає перевагу» складається з різних людей у різних парах, і ланцюжок рветься. Так само рветься «виграє в» у грі «камінь, ножиці, папір», у нетранзитивних кубиках чи в грі Пенні, де на кожну трійку монет є сильніша.

Тому в групі немає «справжнього» переможця, якого правило мало б лише знайти. Три чесні правила ліворуч дають на тих самих бюлетенях три різні поїздки, а парні дуелі не дають жодної: Одеса б'є Карпати, Львів б'є Одесу, а Карпати б'ють Львів. Обираючи правило, група вже обирає результат.

Палата представників США, 5 липня 1956

Практика

Поправка, яка вбила закон

У Палаті представників США поправки голосують раніше за сам закон: спершу закон з поправкою проти закону без неї, потім переможець проти «нічого не ухвалювати». Порядок задають правила, а не голова, але працює він так само, як у нашій задачі.

1956 року Палата розглядала закон про федеральні гроші на будівництво шкіл. Конгресмен Адам Клейтон Павелл запропонував поправку: не давати грошей штатам, які не виконують рішень Верховного суду про скасування сегрегації в школах. Поправку прийняли 225 голосами проти 192, а потім увесь закон провалили 224 голосами проти 194. Перевірити можна в записах поіменних голосувань 84-го Конгресу.

Політолог Вільям Райкер 1958 року пояснив це колом трьох блоків, як на схемі ліворуч: кожен блок менший за половину палати, а будь-які два разом мають більшість. Його пояснення досі сперечаються: частина республіканців могла голосувати за поправку навмисно, щоб потопити закон, а Джеррі Макі в книжці «Democracy Defended» (2003) доводить, що справжнього кола не було. Але сама пастка реальна: поправку, яка робить закон неприйнятним для частини його прихильників, називають «поправкою-вбивцею».

Один день у Конгресі

5 липня 1956 року Палата представників США спершу прийняла поправку Павелла до закону про будівництво шкіл (225 проти 192), а потім відхилила сам закон: за нього проголосували лише 194, проти 224.

2022

Коло в реальних виборах

На виборах шкільного директора в окрузі 4 Окленда (Каліфорнія) переможця Кондорсе не було, показав математик Девід Маккюн. Ті вибори ще й спершу порахували з помилкою, і переможця остаточно визначив суд 2023 року.
